This website was built as a clean, multi-page academic lab website inspired by institutional research-team pages.
It is not a copy of any external website.

HOW TO EDIT TEXT
----------------
1. Open the page you want to edit in VS Code or Notepad++.
2. Press Ctrl + F.
3. Search for the text you want, or search for "EDIT SECTION".
4. Replace the text between the HTML tags.
5. Save the file.
6. Double-click index.html to preview in your browser.

HOW TO EDIT STYLE
-----------------
Open assets/css/style.css.
At the top, change colors such as:
--blue
--blue-dark
--teal
--soft

HOW TO PUBLISH ON GITHUB PAGES
------------------------------
1. Create a GitHub repository.
2. Upload all files and folders from this website.
3. Go to Settings > Pages.
4. Choose Deploy from branch.
5. Select main branch and /root.
6. Save and wait for the website link.
